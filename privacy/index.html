プライバシーポリシー

最終更新日 2026年10月21日

本ポリシーは，個人用のClassroom閲覧ツールにおけるGoogleユーザーデータの取り扱いを説明します．

取得する情報と利用目的

本人がGoogleの認可画面で許可した範囲で，コース情報，お知らせ，課題，教材，添付資料の名前・リンク，本人の提出状況および閲覧可能な採点情報を取得します．授業情報の確認と整理，課題や更新の見落としを減らすために利用します．

Google Classroomの閲覧権限を使用し，投稿や提出内容の変更は行いません．

認証情報

Googleへの認可にはDesktop OAuth clientを使用します．APIへのアクセスと認証更新に必要なトークンを保存します．Googleアカウントのパスワードを本ツールが取得することはありません．

認証情報や取得したClassroomの内容を，この説明サイトや公開リポジトリに掲載しません．

保存・削除

取得処理は本人が管理するPCやVPSで実行します．

取得結果やログ，バックアップは，本人が管理するPCやVPS，利用する連携サービスに保存される場合があります．PC/VPSの保存データには一律の自動削除期限を設けず，用途がなくなった時点で本人が各保存先から削除します．バックアップに残るデータも削除対象に含めます．連携サービスに保存された内容は，各サービスの設定と削除機能に従って管理します．

外部サービスへの転送

授業情報の確認・整理・要約のため，必要な取得結果をOpenAIのCodex / ChatGPTに送信して処理する場合があります．また，通知対象となった授業情報や要約，参照リンクをDiscordに送信する場合があります．OAuth認証情報を要約や通知の内容として送信しません．

各サービスに送信した情報の保存や利用は，利用する契約，アカウント設定および各事業者のポリシーに従います．OpenAIのプライバシーポリシーとDiscordのプライバシーポリシーをご確認ください．

取得したGoogleユーザーデータを販売したり，広告の配信やターゲティングに利用したりしません．

アクセス許可の取り消し

本人はGoogleアカウントの接続管理から本ツールの許可を取り消せます．取り消し後は新たなAPI取得ができなくなります．すでに保存したデータの削除は，保存先で別途行います．

Google APIの利用

Google APIから受け取った情報の利用および他のアプリへの転送は，Limited Use要件を含むGoogle API Services User Data Policyに従います．

サイトの配信

この説明サイトはGitHub Pagesで配信します．本ページにはアクセス解析，広告，ログインフォームを設置していません．ホスティング事業者によるアクセス情報の取り扱いは，GitHubのプライバシーに関する声明をご確認ください．
